# Калькулятор падения напряжения PoE

Учебная программа по дисциплине «Направляющие среды в телекоммуникациях».
Считает, дойдёт ли питание стандарта IEEE 802.3 до устройства PD по витой паре
заданной длины, категории, сечения и материала жилы.

Всё происходит в одном окне: параметры, таблица, график, рекомендация и справка.
Файлы результатов программа не создаёт и браузер не открывает.

Расчёт при 20 °C по номинальному сопротивлению жилы. Это не сертификат канала:
контакты, патч-корды, нагрев и небаланс пар в модель не входят.

## Предустановленные сценарии (Пресеты)

В меню **Пресеты** доступны типичные конфигурации для быстрого старта:
- PoE (802.3af) — 48 В, 12,95 Вт, 100 м, Cat5e
- PoE+ (802.3at) — 50 В, 25,5 Вт, 100 м, Cat5e
- PoE++ Type 3 — 50 В, 51 Вт, 100 м, Cat6
- PoE++ Type 4 — 52 В, 71,3 Вт, 100 м, Cat6a
- Длинная линия Type 4 — 57 В, 71,3 Вт, 150 м, Cat6a 22 AWG
- CCA vs Cu сравнение — Type 2, 100 м

## Готовые файлы

Сборка без установленного Python:

- Linux (x86-64): `dist/linux/PoECalculator`. Это исполняемый файл ELF, не `.exe`:
  на Ubuntu двойной щелчок или `./dist/linux/PoECalculator`.
- Windows: файл `.exe` собирается только на самой Windows, потому что в него
  входят библиотеки Qt этой системы. На Windows запустите `build_windows.bat`,
  результат будет в `dist\windows\PoECalculator.exe`.

## Запуск из исходников

Нужен Python 3.10 или новее. При первом запуске скрипт создаёт `.venv`
рядом с собой и ставит зависимости из `requirements.txt`.

- Windows: двойной щелчок по `run_windows.bat`.
- Ubuntu: двойной щелчок по `run_ubuntu.sh` или в терминале:

```bash
chmod +x run_ubuntu.sh   # один раз, если файл ещё не исполняемый
./run_ubuntu.sh
```

Если на Ubuntu виртуальное окружение не создаётся, не установлен пакет `python3-venv`:

```bash
sudo apt install python3-venv
```

На части выпусков пакет называется по версии, например `python3.12-venv`.

Интерфейс на русском. Тема (светлая или тёмная) запоминается.
График перерисовывается вместе с темой. «Сбросить» возвращает стартовый пример:
PoE+ (802.3at), 50 В, 25,5 Вт, 100 м, Cat5e, 24 AWG, медь.

Настройки окна (размер, положение разделителя, тема) сохраняются между запусками.

Зависимости окна — пакет виджетов PySide6 (`PySide6-Essentials`, без Qt WebEngine)
и matplotlib. Импорт в коде остаётся `PySide6`.

## Формулы

Удельное сопротивление одной жилы `r` берётся при 20 °C.
Для CCA оно умножается на 1,6.

```text
Rж = r · L / 1000

2 пары:  Rпетли = Rж       (в каждом направлении две жилы параллельно)
4 пары:  Rпетли = Rж / 2   (в каждом направлении четыре жилы)

Vpd = (Vpse + √(Vpse² − 4 · Rпетли · Ppd)) / 2
I = Ppd / Vpd
ΔU = I · Rпетли
Pпотерь = I² · Rпетли
Ppse = Ppd + Pпотерь
```

PD потребляет постоянную мощность, поэтому ток зависит от напряжения на его входе.
Берётся больший корень: меньший отвечает неустойчивой точке с тем же потреблением
и большим током. Если дискриминант меньше нуля, питание невозможно.

Вердикт «Работает», если одновременно:

- напряжение на PD не ниже минимума стандарта;
- мощность на выходе PSE не выше предела стандарта;
- ток на пару не выше `I_cable`.

При двух парах ток на пару равен току линии. При четырёх парах ток делится
поровну между двумя парсет. Длина больше 100 м даёт предупреждение, но сама
по себе вердикт не переключает: 100 м — норма канала СКС, а не электрический предел этой модели.

## Справочные данные

| Стандарт | PSE, В | PSE, Вт | PD, Вт | Мин. PD, В | Пары | Ток пары, А |
| --- | --- | --- | --- | --- | --- | --- |
| 802.3af Type 1 | 44–57 | 15,4 | 12,95 | 37 | 2 | 0,350 |
| 802.3at Type 2 | 50–57 | 30 | 25,5 | 42,5 | 2 | 0,600 |
| 802.3bt Type 3 | 50–57 | 60 | 51 | 42,5 | 4 | 0,600 |
| 802.3bt Type 4 | 52–57 | 90 | 71,3 | 41,1 | 4 | 0,960 |

Type 3 в программе — четырёхпарный класс 6. В самом IEEE 802.3
младшие классы Type 3 бывают и двухпарными.

Напряжение PSE по умолчанию — минимум стандарта. В списке ещё максимум
и типовые 48, 50, 52, 54, 56, 57 В, если они входят в диапазон.
Мощность PD по умолчанию — максимум стандарта, спинбокс только уменьшает её
(шаг 0,05 Вт, не ниже 0,1 Вт).

Номинал меди при 20 °C: 24 AWG — 84,2 Ом/км, 23 AWG — 66,8 Ом/км, 22 AWG — 53,0 Ом/км.
Это не максимум TIA-568. Типовые сечения в списках: Cat5e — 24 AWG, Cat6 — 23 и 24 AWG,
Cat6a — 23 и 22 AWG. Сам TIA-568 для этих категорий допускает жилу примерно 22–24 AWG.

## Экспорт отчёта

Меню **Файл → Экспорт отчёта…** (Ctrl+E) сохраняет полный расчёт:
- JSON — для программной обработки
- CSV (разделитель `;`) — для открытия в Excel/LibreOffice

Файл содержит: входные параметры, все расчётные величины, вердикты по каждому ограничению,
максимальную рабочую длину и текстовую рекомендацию.

```text
poe_calculator/
  main.py                 точка входа

  gui/help_dialog.py      справка и текст «О программе»
  gui/themes.py           светлая и тёмная темы
  tests/test_calculator.py
  tests/test_gui_smoke.py
  requirements.txt
  run_windows.bat
  run_ubuntu.sh
  build_windows.bat       сборка .exe на Windows
  build_linux.sh          сборка ELF на Linux
  PoECalculator.spec      спецификация PyInstaller
```

## Тесты

Из каталога `poe_calculator`, когда зависимости уже стоят:

```bash
.venv/bin/python -m pip install pytest
.venv/bin/python -m pytest
```

`pytest` нужен только для проверки и в `requirements.txt` не входит.
На Windows ту же команду выполняет `.venv\Scripts\python.exe`.

## Сборка исполняемых файлов

### Linux

```bash
chmod +x build_linux.sh
./build_linux.sh
```

Результат: `dist/linux/PoECalculator`

### Windows

Дважды кликните по `build_windows.bat` или запустите из cmd/PowerShell.

Результат: `dist\windows\PoECalculator.exe`

Оба скрипта создают виртуальное окружение `.venv`, устанавливают зависимости
и PyInstaller, затем собирают один файл без консоли.
